Smart Pantry Manager

1. Project Overview

Smart Pantry Manager is a Java-based Android application developed for the Mobile Application Development 700 assignment at Richfield Graduate Institute of Technology. The application helps users manage pantry ingredients, monitor quantities, and find recipes based on ingredients they already have.

2. Features

* Add new pantry ingredients.
* View saved ingredients and their quantities.
* Edit existing ingredients.
* Delete ingredients from the pantry.
* Suggest recipes based on available ingredients.
* Apply strict ingredient and quantity matching.
* Display recipe ingredients and preparation instructions.
* Provide application settings.
* Save pantry data locally between app sessions.

3. Technologies Used

* Java
* Android Studio
* XML for user interface layouts
* SQLite for local database storage
* Git and GitHub for version control

4. Database Design

SQLite is used to store pantry information locally on the device. This supports persistent storage, allowing saved ingredients to remain available after the application is closed and reopened.

5. Application Screens

The application includes a home screen, pantry management screen, suggested recipes screen, recipe detail screen, and settings screen.

6. Project Structure

* app/src/main/java/ — Java source code.
* app/src/main/res/layout/ — XML layout files.
* app/src/main/AndroidManifest.xml — Application configuration and activity declarations.
* build.gradle.kts — Gradle build configuration.

7. How to Run the Application

1. Install Android Studio.
2. Clone or download this GitHub repository.
3. Open the project in Android Studio.
4. Allow Gradle to sync and download the required dependencies.
5. Start an Android emulator or connect a compatible Android device.
6. Click the Run button to build and launch the application.

8. Version Control

Git and GitHub are used to track development changes and maintain the project’s source code history.
